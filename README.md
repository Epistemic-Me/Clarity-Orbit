# Clarity Orbit

Weekly ROI investment tracker for startup founders. Allocate your team's hours across opportunities, track projections, and make better capital allocation decisions in a 15-minute weekly meeting.

## Features

- **Single-screen allocation table** — all opportunities visible at once, no scrolling
- **Concentric ring model** — Inner (platform product) / Middle (platform services) / Outer (pure services) with visual ring grouping
- **Constraint engine** — auto-balances allocations within capacity limits (outer ring hours reduced first)
- **Live projections** — milestone timelines update instantly as you adjust hours
- **Keyboard-first** — Arrow keys (±1), Shift+Arrow (±5), Tab/Enter navigation, `/` command bar
- **Quick commands** — type `robert +5 builder` to shift hours without clicking
- **Week-over-week deltas** — see what changed from last week at a glance
- **4-week sparklines** — spot allocation drift in trending mini-charts
- **Target date tracking** — projections show "on track ✓" or "3 wks late" against deadlines
- **Lock In summaries** — one-click meeting summary copied to clipboard
- **Dynamic team** — add/remove/rename team members with custom capacity and rates
- **Configurable opportunities** — add/edit/remove opportunities, change their ring
- **localStorage persistence** — data survives browser refresh
- **Demand gen funnel** — track content hours → visitors → leads → pipeline with CPL calculation

## Quick Start

```bash
npm install
npm run dev
```
